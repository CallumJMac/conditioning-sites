The code in this repository is MIT-licensed (`LICENSE`). Audio generated by the
models, including the samples in `docs/samples/`, is not covered by that
licence. Each clip carries the licence of the model that produced it:

| Model | Output licence | Conditions |
|---|---|---|
| Qwen3-TTS 0.6B / 1.7B | Apache-2.0 | Attribution |
| CosyVoice-300M, CosyVoice 3 | Apache-2.0 | Attribution |
| Chatterbox | MIT | Outputs carry Resemble AI's imperceptible PerTh watermark |
| XTTS-v2 | Coqui Public Model License 1.0.0 | Non-commercial use only; no direct or indirect payment may arise from the output |
| F5-TTS v1 | CC-BY-NC-4.0 | Non-commercial use only, with attribution |

Sample file names start with the system name (`docs/samples/<item>/<system>_<condition>.mp3`;
factorial cells are CosyVoice-300M). Prompts and held-out recordings come from
LibriTTS-R (CC-BY-4.0) and Common Voice (CC0) via Seed-TTS-eval.

All samples are synthetic voices of corpus speakers, released for research.
Do not use them to impersonate the speakers.
